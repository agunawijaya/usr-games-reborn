# Hall hero frames

Screenshots of the live Hall, not mockups, rendered at 1920×1080 from development-only screenshot
scenes (`apps/hall/src/scenes/scenes.ts`).

## Machine Room (prompt 00, approved)

Eighteen frames: three screens (Home with the today strip, the man page for `robots`, and the home
directory at rank `staff`) in each of the three palettes, in light and dark. File names follow
`<screen>-<palette>-<appearance>.png`.

## Console Home and Holo Collection (prompt 00a, awaiting approval)

Ten frames, each by Day and by Night (`-day.png`, `-night.png`):

| Frames             | What they show                                                                                                 |
| ------------------ | -------------------------------------------------------------------------------------------------------------- |
| `picker-*`         | The first-visit style picker: the three styles as live miniatures of the real Home, Console Home pre-selected. |
| `console-home-*`   | Console Home with Today's pick (sail) in the hero and the rail below.                                          |
| `console-detail-*` | The Console Home game page for `robots`.                                                                       |
| `holo-home-*`      | Holo Collection's Home with the `robots` card tilted under the pointer.                                        |
| `holo-album-*`     | The album: every achievement as a card, earned ones in foil.                                                   |

## The scene data

- **The player:** a demo player, `ada`, about eight weeks in, generated by the real progression
  engine from a seeded run of sessions. XP, level, packages, streak, quests and stats are the
  engine's own output.
- **The catalog:** the eight games that prompt 01 adopts are shown as already shipped. Their
  achievements in these frames are illustrative placeholders; prompt 01 defines the real ones. The
  other 22 games are the real placeholders, coming soon.
- **The art:** the key art for sail, robots, trek and pom is the Hall's code-drawn placeholder art
  (`apps/hall/src/core/art/key-art/`) until each game supplies its own poster. Every other game shows
  the procedural poster made from its emblem and accent.
- **The clock:** pinned to Thursday 1 October 2026, 21:42:07, so the week's quests are part-way done
  and every frame is reproducible. Animation (ambience, key art, breathing cards) is frozen at one
  moment; in the running Hall it moves.

## Regenerating

Start the dev server (`pnpm dev`), then:

```sh
pnpm --filter @usr-games/hall shots                     # Machine Room: home, man, profile
pnpm --filter @usr-games/hall shots --scenes picker,console-home,console-detail,holo-home,holo-album
```

Add `--themes sunset`, `--appearances dark`, `--width 1280 --height 720` or `--out <dir>` to render a
subset elsewhere. Any scene opens in a browser the same way, for example
`http://localhost:5173/?scene=holo-album&appearance=dark&freeze=1`.
