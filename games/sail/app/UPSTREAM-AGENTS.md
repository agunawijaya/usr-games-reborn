# AGENTS.md — `sail / fancy-web` (*Broadside — Wooden Walls*)

Port-level instructions. Read the game-level [`../../AGENTS.md`](../../AGENTS.md)
and the root [`../../../../AGENTS.md`](../../../../AGENTS.md) first.

## Identity

**fancy-web** per ADR-006: a cinematic, procedurally generated 3D port.
Rules faithful to the original (ported from the C); presentation free.

## Hard rules for this port

1. **Zero raster assets in `src/`** ([ADR 002](./docs/decisions/002-zero-raster-assets.md)).
   No image files, no `data:image`, no texture/image loaders. Runtime
   Canvas 2D / DataTexture / render targets are fine. `npm run check:raster`
   must pass. Screenshots belong in `media/` only.
2. **The engine is pure** (`src/engine/`): no DOM, Three.js, timers or
   `Math.random`. All randomness goes through the state's RNG.
   `resolveTurn(state, orders)` must stay deterministic and must not
   mutate its input. Run `npm test` after any engine change.
3. **Rules come from the C.** Cite the upstream `file:line` you port.
   Any deviation from the C or `spec.md` needs a line in
   [ADR 004](./docs/decisions/004-rules-fidelity.md) (or a new ADR) and a test.
4. **Nothing decorative.** Visual state must derive from engine state or
   engine events (see the table in [ADR 005](./docs/decisions/005-ship-rigging-and-masts.md)).
5. **Visual changes are screenshotted and critiqued** before they land
   (`scripts/snap.mjs`, `npm run shots`); record what was wrong and why in
   [`docs/notes.md`](./docs/notes.md).
6. Keep it zero-build: vanilla ES modules, the vendored Three.js in
   `src/vendor/` (update both files together; pin the version in
   `package.json`).

## Where things are

- Rules: `src/engine/` — `turn.js` is the entry point; `data.js` is
  generated by `scripts/extract-data.mjs`.
- Presentation: `src/render/` (world, ocean, ships, fx, cinematic,
  camera, chart), `src/ui/`, `src/audio/`, glued by `src/main.js`.
- Tests: `tests/` (node), `scripts/ui-smoke.mjs` and `scripts/ui-flows.mjs` (browser).
- Architecture: [`docs/architecture.md`](./docs/architecture.md).

## URL parameters (demo, screenshots, debugging)

`scenario`, `ship`, `seed`, `captain`, `initL`, `initR` start a battle;
`auto=N` plays N turns (`autoorders=none` for empty orders); `cine=0`
skips cinematics, `last=show` plays the last one; `stage=` edits the
initial state (`1:hull=3,rig1=0;w:speed=7`); `view=tactical`;
`quality=low`; `reduced=1`; `hud=0` photo mode; `focus`, `yaw`, `pitch`,
`dist` frame the camera; `readyAt=fire|move|idle|end` + `readyDelay`
tell `snap.mjs` when to capture.
